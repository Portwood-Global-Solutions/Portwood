#### Details worth checking on an existing installation

- **Signers and senders.** A Portwood User can send a request. The record-page picker shows active templates for the record's base object. Korean and other non-Latin names and dates appear in the signed PDF and certificate. The signing viewer redraws visible pages when zoomed. Initials prompts follow the typed-only setting. A certificate's verification link is clickable across wrapped lines when a valid site URL is configured. [Signing access](../../UserGuide.md#manage-access)
- **Images and downloads.** Reactivate an image in Assets to restore its existing tag. Older image assets with a blank asset type remain available. Same-org Salesforce File images in rich-text values render on download. The download link behind a preview opens that specific generated File. [Images and assets](../../UserGuide.md#images-and-assets)
- **Forms and Office.** Reupload a compressed PDF form as a new version if flattening requests it. Test Auto-size fields and check existing appearances. PowerPoint produces PPTX. Macro-enabled Excel retains macros in background generation. Check each sheet after a large run. [Office formats](../../UserGuide.md#office-formats)
- **Command Hub.** The template library loads directly and the sidebar appears while access-dependent actions are checked. **Back to Library** in the legacy designer returns to the designer picker and prompts before discarding edits. [Find your way around](../../UserGuide.md#find-your-way)
