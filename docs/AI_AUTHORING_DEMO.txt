To create another:
1. My templates > Create template > Generate with AI.
2. Name it; Next: Describe your document. No base-object or field picker is required.
3. Upload one PDF or DOCX. Wait for Ready. Choose Lato / Regular under Document font.
4. Send a message to Agentforce. Example:
   Closely recreate this Project Quote, preserving its wording, Portwood logo,
   four product columns and closing statement. Use the selected Lato regular and
   bold faces, bind customer and pricing to Salesforce Quote data, and fit the
   sample on one Letter page.
5. Reply to any business questions. Review Ready to design; refine it naturally
   (e.g. "Include all quote lines; no row limit"). Generate document with Agentforce.
   Choose the Northstar Quote, then Open in Designer.
6. Review field meanings, native PDF, page breaks and fonts. Save as New Version.

Planning uses native Agentforce and actual readable Salesforce schema. It does
not retrieve customer record values. Portwood validates structured filters, sorting
and relationships in USER_MODE before handing the query shape to HTML generation.
Custom providers need the optional Callable queryPlanning / planQuery capability.
Activate DocGen_Query_Plan, DocGen_Query_Reference, DocGen_HTML_Body and
DocGen_HTML_Reference in the updated extension (currently scratch-only).

The full HTML prompt ends with the accumulated customer requests. Earlier sections contain the rendering
contract, canonical repeating tables, allowed data shape, image assets, exact
approved font tags, language caveats and reference handling. Examples are untrusted
reference content, not instructions. The default is close recreation; the brief
can request a redesign. Designer and Canvas remain separate products under the
Designer / Canvas choice; Existing template is the third authoring route.

The tested default is GPT 5.4 through native Agentforce ConnectApi / Prompt Builder.
The scratch trial has zero Advanced-model allowance; GPT 5.5 returned a quota
error. Model choice remains configurable by the admin. The original proposal
scratch has the updated base UI/code but lacks the Agentforce entitlement.

PDFs use private ContentDocument grounding. DOCX uses async native Word-to-HTML
preparation, including main-body PNG/JPEG images. The UI uses the 15 MB Agentforce
file budget; expanded Word content can hit processing/prompt limits. Complex
layouts, Word drawings and header/footer images can need a PDF export or manual
adjustments. Salesforce sends inputs to its configured model; private Files storage
does not prevent model processing.

Advanced print guidance covers page-break-inside:avoid for normal rows, nowrap
for short amounts/codes only, repeating thead, explicit widths, headings and
compact totals staying together, and deliberate page breaks. Oversized rows can
still split. Long descriptions should wrap. Native PDF review remains required.
